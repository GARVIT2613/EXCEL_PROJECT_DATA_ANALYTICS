# **Electric Vehicle Market Intelligence & Infrastructure Analytics Dashboard**  
<img width="1472" height="749" alt="P-1,DASHBOARD" src="https://github.com/user-attachments/assets/b4a32923-33af-4107-8c9c-7004584b26d6" />  
This Electric Vehicle Market Intelligence & Infrastructure Analytics Dashboard was created to analyze the growth of the EV industry and understand trends related to vehicle sales, charging infrastructure, technology performance, and environmental impact. 

The dashboard provides interactive insights into EV adoption across brands, countries, and vehicle categories using Excel’s data analysis capabilities. It integrates multiple data sources and visualizations to help explore EV market performance
